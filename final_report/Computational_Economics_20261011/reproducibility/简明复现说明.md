# 简明复现说明

本包对应 Online Resource 2。它包含全部 26 个收到的 v3.8 归档文件，
其中 23 个实验批次合计 5,901 次执行；没有新增模拟，也没有重写原始数据。

从本目录使用 Python 3.12.14 执行：

```text
python -m pip install -r requirements-verification.txt
python analysis/verify_package.py
python analysis/reproduce.py
python artwork/build_artwork.py
```

第一条核验命令仅依赖 Python 标准库，检查文件指纹；第二条重新聚合归档，
并核对 31 项结果，输出写入 `output/recomputed`；第三条重绘 15 幅图，
输出写入 `output/artwork`。图的源数据和流程图几何信息位于 `accepted/stage04`。
流程图 PNG 预览需要 Poppler；没有 Poppler 仍可生成 PDF、EPS、SVG 和 drawio。

`requirements-verification.txt` 记录修订核验环境，不代表未知的原实验环境。
`model/requirements.txt` 是原模型更广泛的运行依赖，归档聚合不需要全部安装。
`accepted` 保存已接受结果，`analysis/legacy` 保存未改动的原分析脚本。
后续证据导出使用已接受的阶段一 `tables.json` 作为明确输入；它不是本次独立重建的产物。

450 条探索性 LHS 记录缺少实际参数向量；9 次已知 census 重放不增加独立样本量。
这些限制已写入正文和 Online Resource 1。作者应在投稿前确认资料共享权和最终文本。
