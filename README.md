# 原始积累模型 (Primitive Accumulation Model)

**四部门政治经济学模拟实验室 —— 数字时代原始积累的可行路径、多维评价与代价分布**

> **版本**：v3.4 (2026-07-05)
>
> **核心立场**：任何一种积累策略都有其内在矛盾，在一定条件下都会被引爆。本模型不预设哪种策略更好——它提供的是一个让数据说话的分析框架。服务业作为第四部门正式纳入模型，Rodrik (2024) 的"服务业是发展主引擎"论点可以在此框架中检验。金融部门、国际环境、气候维度不再是"已知盲区"——它们是模型的可计算机制。

---

## 一、这个模型在回答什么问题

本模型的意义在于：**在数字时代，当"工业→数字"成为新的积累链条时，为"如何积累、代价谁担、反哺能否兑现"这三个经典问题提供一个可计算、可比较、可探索的分析框架。**

它直接服务的核心问题只有一个：

> **对于一个无法将代价外部化的后发国家，在技术封锁和民生诉求双重压力下，应该选择什么样的积累策略组合（纯策略或混合策略），才能在经济追赶与人的发展之间找到合意的平衡？**

具体展开为四个子问题：

### 子问题一：比较与诊断

在相同的初始条件和外部环境下，不同的积累策略（及其混合）在经济效率、民生福祉、结构健康、发展韧性和主权自主五个维度上，分别会产生什么样的表现差异？每种策略的"命门"——也就是它不可消除的内在矛盾——会在什么条件下被引爆？

这不是在问"哪种策略更好"，而是在问：**每一种策略在哪些方面会做得好，在哪些方面会做得差，在什么条件下会失败。**

### 子问题二：边界与红线探索

在什么条件（参数组合、外部场景）下，特定的积累策略会触发人道主义红线——如大规模长期失业、极端贫困、群体灭绝性代价——从而从"可接受的代价"滑向"不可接受的失败"？

这意味着模型不仅要关注"系统是否崩溃"，更要关注**人的底线是否被突破**。一个没有崩溃但让40%人口陷入赤贫的路径，在这个框架中也是不可接受的。

### 子问题三：反哺机制的有效性验证

"数字反哺工业"是跳跃式积累（策略B）的核心承诺——先集中资源发展数字部门，成熟后再反哺工业。但这个承诺在什么制度条件下会兑现？在什么条件下会落空？是否存在最优的反哺时机和强度？反哺失败后会发生什么？

### 子问题四：策略空间的拓展

现实中没有一个国家走纯粹的某一条路径。是否存在一种主次分明的混合策略——比如以跳跃式积累为主、但同时保留渐进式积累的工业保护底色——能够在保持经济追赶动能的同时，有效规避纯策略的致命弱点，从而拓展发展的可能性空间？

### 子问题五：模型的自我认知 (v3.2)

一个计算模型的价值不仅在于它能产生什么结论，还在于它**知道自己的局限**。本模型内置了一套学术验证体系来回答以下元问题：
- **可证伪性**：当三种策略参数完全相同时，模型是否输出无差异的结果？（零假设基线测试）
- **核算可信度**：SFC会计闭合的残差在系统压力下是否会膨胀为"减震器"？（残差监控）
- **发现vs预设**：模型产生的动态是否超出了设计者预定义的分类？（通用异常检测）
- **评价独立性**：五个评价维度之间是否存在高度共线性，使多维评价徒有其表？（相关性矩阵）
- **断裂覆盖度**：是否所有预定义的断裂模式都在合理的参数范围内可被触发？是否存在从未触发的"休眠断裂"？（断裂触发矩阵）

## 二、设计哲学：从"哪种策略更好"到"在什么条件下产生什么结果"

### 2.1 这个模型不是什么

在说明它是什么之前，有必要澄清它不是什么：

- **不是预测模型**。它不预测某个特定国家未来会怎样。它的价值不在于"答案正确"，而在于"暴露我们不知道的东西"——如果一个参数组合产生了反直觉的崩溃或存活，那正是最有价值的发现。
- **不是规范性宣言**。它不告诉决策者"你应该选策略A"。它告诉决策者：你选了策略A，它在这些维度上会好，在这些维度上会差，在这些条件下会出问题。选择什么，是你自己的价值判断。
- **不是增长至上主义的**。它不认为GDP增长是终极判准。民生福祉、结构健康、主权自主与经济增长是平等的评价维度。

### 2.2 四条核心原则

**原则一：多维评价替代单维判准。** 模型的核心判准从单纯的"崩溃率/存活时间"扩展为五个维度——经济活力、民生福祉、发展韧性、结构健康、主权自主。每个维度都有数个可量化的子指标，最终聚合成综合发展指数（CDI）。但CDI的权重是开放的——不同的价值偏好会得出不同的排序。

**原则二：民生作为硬约束。** 人道主义红线是 go/no-go 的硬约束——突破了就标记为"不可接受"，不与经济表现做交易。一个CDI=0.9但让40%人口赤贫的路径不被接受。这是规范性立场：**人类社会的发展底线不可逾越。**

**原则三：每种策略都有缺陷，每一种都值得被严肃对待。** 渐进式积累（A）有"速度陷阱"——世界太快时线性升级跟不上指数增长；跳跃式积累（B）有"撕裂陷阱"——赢家通吃到极致社会契约破裂；替代式积累（C）有"依附陷阱"——FDI和资源同时断裂时无自救能力。模型的任务不是证明某一种更好，而是完整刻画每一种的多维画像。

**原则四：混合策略是一等公民。** 现实中没有纯粹的路径。模型支持任意比例的λ向量混合——主导策略权重过半（≥50%），次要策略不超三成（≤30%），第三策略不过两成（≤20%）——确保策略底色明确的同时保留了弹性空间。

**原则五：方法论自觉性是学术质量的标志。** (v3.2) 模型不假装覆盖了它没覆盖的东西。它有零假设基线测试来证明策略差异来自参数设计而非数值噪声；它有 SFC 残差监控来确保核算框架在压力下不充当"减震器"；它有通用异常检测器来验证预定义断裂是否遗漏了涌现的异常模式；它有五维相关性矩阵来暴露评价维度之间的张力。盲区被诚实标记，结论的脆弱性被主动测试。

## 四、四部门 + 低端服务业缓冲带：生产的骨架 (v3.3)

### 4.1 基础部门 (B)

农业、资源开采、低端制造。生产函数受资源约束和数字化渗透两方面影响。

- **核心逻辑**：资源出口型国家的基础部门承担着"养活人口+赚取外汇"的双重任务
- **数字化影响**：有限——精准农业、资源勘探数字化等，但整体数字化弹性较低
- **与工业的关系**：提供原材料和基本消费品；工业萎缩时，劳动力先经服务业缓冲带吸收，服务业饱和后才回流至基础部门→压低工资→过早去工业化

### 4.2 工业部门 (I)

制造、建筑、硬件生产。模型中的"中坚力量"——技术追赶的主要载体，就业的主要提供者，政治支持度的最重要支柱。

- **核心逻辑**：工业是三种策略博弈的核心战场——A保护它、B牺牲它以换取数字优先、C可能因荷兰病而失去它
- **数字密度 (digital_density)**：v2.2新增。工业资本中嵌入数字技术的比例[0,1]。高数字密度的工业更高效、更善于吸收数字技术，也更接近"智能制造"
- **知识扩散**：从数字部门向工业的技术扩散不是自动的——需要制度支持和人力资本基础
- **去工业化诊断**：区分四种类型——正常（升级到高技能服务）、过早（退化到低端服务）、崩溃型、跳跃诱发型（策略B过度提取）

### 4.3 数字部门 (D)

软件、数据服务、AI。积累的新引擎，也是模型中最"双刃"的部门。

- **核心逻辑**：数字化水平遵循S曲线，经历"基础设施→应用→数据驱动"三阶段
- **数据资产**：不是同质的——生产者数据（工业IoT/供应链）与消费者数据（平台/社交）有不同的生产力贡献和外部性
- **网络效应**：用户规模带来正向外部性，但也可能导致垄断和数据殖民
- **依附风险**：数字产业如果依赖外国云/芯片/OS/数据存储/算法，即使规模大也并不自主

### 4.4 服务业部门 (S) — v3.3 新增

零售、餐饮、物流、家政、零工经济。**劳动力吸收的主战场**——工业释放的劳动力中，技能不足以进入数字部门的，进入服务业而非直接失业。

- **核心逻辑**：服务业是就业的"缓冲海绵"。资本密集度低（α_s=0.25），劳动份额高（~75%），数字化增益中等——数字平台（外卖/打车/电商）可显著提升服务业效率
- **生产函数**：Cobb-Douglas，低资本密集 + 数字平台增益 + 网络效应（用户规模→匹配效率）
- **与工业/数字的关系**：工业流出→服务业吸收（Rodrik 的"过早去工业化后转入低端服务业"）；数字平台赋能→服务业效率提升（Rodrik 的"数字工具辅助低技能劳动力"）
- **低端服务业缓冲带**：不仅如此，模型还追踪了正式服务业之外的"非正式就业"（`informal_service_L`）——那些连正式服务业都进不去的劳动力，构成"隐藏失业"
- **投资逻辑**：三种策略对服务业的投资比例不同——A给服务业10-15%（温和），B压缩到5%（数字优先），C给15%（劳动力密集型发展）

## 五、三种积累策略及其混合

### 5.1 策略A：渐进积累

**核心逻辑**：保护工业 + 温和提取 + 数字化升级存量资产。先稳住工业基本盘，再用数字技术逐步改造它。

**投资分配**：按存量资本比例分配，略偏向数字部门（额外权重约10%）。

**内生成本**：

| 成本 | 机制 | 触发条件 |
|------|------|---------|
| 保护僵化 | 保护过剩 → 落后产能占用资本 → 效率损失 | safety_margin > 有效资本比 |
| 渐进时间税 | 走得太慢 → 世界在正常前进 → 追赶窗口自然缩小 | g_d < g_world 持续累积 |
| 既得利益刚性 | 长期保护 → 利益集团形成 → 改革阻力 | 保护持续时间 > 15年 |
| 中间收入陷阱 | 保护有余+升级不足 → 工业不够先进、数字不够强大 | DD_i<0.3 + G>4 + 持续>10年 |

**命门——速度陷阱**：当世界技术前沿增长超过5%/年时，A的线性升级无法匹配指数的前沿增长。技术差距加速扩大，工业因竞争力下降而萎缩。

### 5.2 策略B：跳跃积累

**核心逻辑**：高提取率（30-60%）→ 集中资源砸向数字部门 → 数字产业成熟后反哺工业和基础部门。

**投资分配**：跳跃期数字部门获得60-85%的投资份额；反哺期触发条件为DL_d≥0.5，成功后投资比例调整。

**内生成本**：

| 成本 | 机制 | 触发条件 |
|------|------|---------|
| 就业破坏 | 高提取→工业投资不足→就业流失；数字部门只能吸收部分（技能不匹配） | τ > 30% |
| 消费萎缩 | 居民可支配收入占比下降→国内需求不足→工业产出受需求侧约束 | τ 持续高 |
| 资产泡沫 | 数字部门超额利润(r_d>25%)→财富集中→泡沫压力积累 | 泡沫压力>2.0时可能破裂 |
| 人才虹吸 | 数字高薪吸走工业最优人才→工业人力资本持续下降 | r_d/r_i > 2.0 |

**命门——撕裂陷阱**：工业/数字代价比超过2.5时，社会裂痕开始不可逆地扩大。超过4.0时，即使经济数据好看，政治合法性也已崩溃。

**反哺的不确定性**：反哺不是自动发生的。数字部门利润率越高→截留动机越强。制度能力越弱→越无法强制反哺。外部竞争压力越大→数字部门越有借口"需要更多投资"。

### 5.3 策略C：替代积累

**核心逻辑**：依靠资源出口赚取外汇 + 引进外资和技术 → 用外部资源替代内部积累。

**投资分配**：数字部门从FDI和技术进口中获益；工业从资源出口中获益；基础部门被挤压。

**内生成本**：

| 成本 | 机制 | 触发条件 |
|------|------|---------|
| 荷兰病 | 资源出口繁荣→汇率升值→工业竞争力丧失 | 资源出口 > 50% |
| 政策俘获 | 外部依赖>75%→外资利益绑架国内政策 | ext_dep > 0.75 |
| 技术退化 | 进口>60%+依赖>60%→自主创新被"挤出" | 长期技术进口依赖 |
| 消费主义陷阱 | FDI流向消费领域→储蓄率下降→国内积累能力减弱 | FDI_consumer/FDI>50% |
| 人才外流 | 依附→高技能人才向外流动 | 技术进口>60%且国内高技能岗位不足 |

**命门——依附陷阱（三重诅咒）**：FDI和资源出口同时断裂时触发"完美风暴"——技术进口断绝+积累基金枯竭→技术差距加速扩大→自主创新因长期依赖而退化→无法自救。

### 5.4 混合策略 (v3.0)

**核心创新**：以上三种策略并非互斥。现实中任何国家都是混合体——中国是A底色+B成分+C成分，韩国是B底色+A成分，印度是B底色+A成分。

**数学形式**：λ = [λ_A, λ_B, λ_C]，λ_j ≥ 0，Σλ_j = 1。

**约束规则**（确保主次分明）：
- 主导策略 ≥ 50%（底色明确）
- 次要策略 ≤ 30%
- 第三策略 ≤ 20%

**混合体现在三个层面**：
1. **提取率混合**：τ_effective = λ_A·τ_A + λ_B·τ_B + λ_C·τ_C
2. **投资分配混合**：各纯策略的分配逻辑按λ加权后归一化
3. **内生成本混合**：各纯策略的成本按λ权重缩放——混合比例越小，某纯策略的典型成本越被稀释，但不会完全消失

**13种标准配比**：3种纯策略 + 6种主导混合 + 3种双元混合 + 1种均匀混合，覆盖了从"完全纯"到"完全均匀"的全谱系。

**与纯策略的关系**：λ = [1.0, 0.0, 0.0]时，混合策略完全退化为纯策略A——向后兼容。

## 六、五维评价体系与综合发展指数 CDI (v3.0 核心)

### 6.1 为什么需要五维评价

传统的"崩溃率"判准有两个问题：(1) 它是一个二分变量，无法区分"勉强活着"和"繁荣"；(2) 它可能遮蔽代价——一个没有崩溃但让大量人口陷入赤贫的路径在"崩溃率"框架中是"成功"的。

五维评价回答的不再是"活下来了吗"，而是**"以什么方式活着"**。

### 6.2 五个维度

```
               经济活力 (Economy)
                  /\
                 /  \
                /    \
      主权自主  /      \  民生福祉 (Livelihood) ★
      (Sov)   /   CDI   \
             /            \
            /              \
  结构健康 ───────────────── 发展韧性 (Resilience)
  (Structure)
```

#### 维度一：经济活力 (Economic Vitality)

衡量经济的数量表现。包含：人均GDP增长率、投资效率(ICOR)、产出波动性、数字部门增加值占比（倒U型——太低或太高都不好）、出口竞争力。

#### 维度二：民生福祉 (Livelihood & Human Welfare) ★ 核心维度

衡量人的实际生活体验。包含：综合福利指数、贫困人口比例（消费<中位数50%）、代价基尼系数（代价在四个群组间的分布）、社会流动性、就业健康、健康水平、教育公平度、代际公平指数、心理/社会成本。

> **v3.0的差异化定位**：民生福祉在默认权重中占30%（其他维度各17.5%），反映了"以人民为中心"的规范性立场。但这只是默认——CDI框架允许使用者按自身价值偏好调整权重。

#### 维度三：发展韧性 (Developmental Resilience)

衡量系统吸收冲击、适应变化的能力。包含：EWS韧性指数、技术自主度、财政缓冲空间、外汇储备充足率、资源自给率、制度响应速度。

#### 维度四：结构健康 (Structural Health)

衡量经济结构的合理性。包含：去工业化质量、工业数字密度、部门间工资差距、技能匹配度、产业结构多样化、创新扩散速率。

#### 维度五：主权与自主 (Sovereignty & Autonomy)

衡量独立决策能力。包含：综合自主指数（数字依附的反向）、数据主权度、标准参与权、政策自主空间、供应链安全、资本账户自主。

### 6.3 综合发展指数 CDI

CDI是五个维度的加权和，支持五种预设权重方案：

| 方案 | 经济 | 民生 | 韧性 | 结构 | 主权 | 适用视角 |
|------|------|------|------|------|------|---------|
| **默认(民生优先)** | 17.5% | **30%** | 17.5% | 17.5% | 17.5% | 论文默认：以人的发展为核心 |
| 增长优先 | 35% | 20% | 15% | 15% | 15% | 传统发展经济学视角 |
| 民生极致 | 10% | 45% | 15% | 15% | 15% | 最强调分配正义 |
| 安全优先 | 10% | 20% | 25% | 15% | 30% | 地缘政治紧张期的视角 |
| 均衡发展 | 20% | 20% | 20% | 20% | 20% | 无偏好的中性基准 |

权重变化本身就是一个实验维度——探索不同价值观下哪种策略更优。如果核心发现在所有权重方案下都稳健，这本身就是方法论贡献。

### 6.4 时间维度的修正

- **时序加权**：近期福祉权重大于远期（贴现率 δ ≈ 0.02/年），但不极端——后代人不会被完全忽略
- **波动惩罚**：如果民生指标出现剧烈波动，即使均值尚可也要扣分——不稳定的好日子不如稳定的过得去
- **趋势评分**：终点是否在改善——方向比位置更重要

## 七、人道主义红线：不可逾越的底线 (v3.0)

### 7.1 为什么需要红线

没有红线约束的模型可能产生这样的结果：一条路径CDI=0.85、GDP飙升，但40%人口陷入赤贫。因为没有触发"系统崩溃"，这条路径在v2.2的框架中可能被视为"成功"。

人道主义红线修正了这一点。它反映了本研究的规范性立场：**某些人类发展的底线不可逾越。** 高增长不能补偿极端贫困；系统不崩溃不等于成功。

### 7.2 七条红线

| 红线 | 级别 | 触发条件 |
|------|------|---------|
| 极端贫困 | **失败** | 超过40%人口处于贫困线（消费<中位数50%）以下 |
| 长期大规模失业 | **失败** | 失业率>20%持续超过15年 |
| 基本生存危机 | **失败** | 基础部门人均产出低于生存线 |
| 群组灭绝性代价 | **失败** | 任一家庭群组人口下降>50%且福利<0.20 |
| 代际掠夺 | 警告 | 当代人代价超过后代收益3倍 |
| 大规模技能贬值 | 警告 | 工业劳动者技能持续贬值>30%且无再培训 |
| 儿童发展危机 | 警告 | 教育投入/GDP持续<2%且人力资本下降 |

**两级机制**：
- **人道主义失败**：红线触发→路径从"可接受"列表中移除→不参与策略排序
- **人道主义警告**：接近红线→路径仍可排序→但报告中显式标注警告信息

## 八、民生子模块：健康·教育·社保·安全感 (v3.0)

v2.2的welfare模块计算了一个聚合福利指数。v3.0将其拆分为四个可独立追踪的维度。

### 8.1 健康

**影响因素**：基础部门产出/人口（粮食安全）、公共医疗支出/GDP（医疗服务可及性）、工业污染排放（与环保投资相关）、失业→精神健康恶化的间接效应。

**反馈到经济系统**：不健康的人口→人力资本下降→吸收能力和创新潜力下降。

### 8.2 教育

**影响因素**：公共教育支出/GDP、教育公平度（群组间技能差距）、技能不匹配度（数字部门需求vs现有技能供给）、代际流动性。

**反馈到经济系统**：教育→人力资本H→技术创新和吸收能力。技能不匹配→结构性失业→社会不满。

### 8.3 社会保障

**影响因素**：失业保险覆盖率（人均补偿/平均工资）、养老金充足度（积累基金分配）、住房可负担性（可支配收入/住房成本）。

**反馈到经济系统**：社保→消费平滑→总需求稳定→增长稳定性；社保缺口→预防性储蓄→消费不足。

### 8.4 民生安全感

**影响因素**：就业稳定性预期（失业率水平+趋势）、收入增长预期、制度信任度（与政治支持度关联）。

**反馈到经济系统**：低安全感→预防性储蓄增加→消费减少→总需求不足→增长放缓。这是"软"指标，但在政治经济学上极为重要——对未来悲观的人即使当前过得去也会收缩消费。

## 九、风险监测体系

### 9.1 九种断裂模式

| 断裂模式 | 触发条件 | 级联效应 |
|---------|---------|---------|
| 工业枯萎 | K_i/K_i(0) < 0.30 | ← tech_lock_in 加速 |
| 技术锁死 | 技术差距 G > 10 | ← dependency_trap 加速 |
| 依附固化 | 外部依赖 > 0.70 | — |
| 社会崩溃 | 失业 > 0.25 或 福利 < 0.30 | ← 多重级联加速 |
| 财政崩溃 | 债务/GDP > 1.50 | ← industrial_withering |
| 人力资本崩溃 | H_avg < 0.50（持续10年+） | ← social_collapse |
| 数据殖民 | 消费者数据海外存储 > 0.80 | — |
| 过早去工业化 | 工业劳动力→基础部门退行 | → social_collapse |
| 跳跃诱发去工业化 | B过度提取+反哺失败 | — |

断裂之间存在级联效应——一种断裂可能触发或加速另一种。

### 9.2 EWS早期预警系统

在断裂发生之前，系统通常已经发出了统计预警信号。EWS系统基于滑动窗口（40步）实时监测：

- **临界慢化**：方差上升 + 自相关趋势上升 → 系统从扰动中恢复的速度变慢
- **闪烁检测**：峰度异常 + 双模态出现 → 系统在两个稳定状态间快速跳跃
- **爆炸同步**：部门间Kuramoto序参量耦合强度趋近临界值 → 级联崩溃的前兆
- **韧性指数** (v2.2)：综合恢复速度+抗扰动幅度+压力持续性 → 区分"这是结构性高压还是真的在逼近临界点"

### 9.3 尾部风险

所有策略都无法规避的意外事件：供应链冲击、国际金融冲击、技术路线突变、社会动荡。校准为低频率（年均~1-2%）但真实影响，有冷却期，严重程度取决于系统当前状态——制度能力强的国家抗打击，脆弱的国家更惨。

- 泡沫是"硬破裂"还是"软着陆"

## 十一、国情预设：六个后发国家的初始条件 (v3.1)

### 11.1 为什么需要国情预设

一个资源富国和一个制造业大国在"积累路径选择"这个问题上，起点完全不同。如果所有模拟都从同一组硬编码的初始值出发，模型就无法回答"不同国情应该选不同策略"这一核心问题。

v3.1 的国情预设体系将初始条件参数化，使用户可以一键选择国家类型。**国情、策略、国际场景三个维度彼此正交**——选什么国家 × 选什么策略 × 处在什么国际环境，三者独立组合。

### 11.2 六种国情

| 预设 | 典型参照 | K_i | K_d | R | H_i | 人口 | 制度 | 自然策略倾向 |
|------|---------|-----|-----|---|-----|------|------|------------|
| **制造业大国** | 中国c.2000, 韩国c.1980 | 400 | 15 | 0.60 | 1.0 | 73 | 0.65 | A |
| **资源富国** | 沙特, 尼日利亚, 委内瑞拉 | 100 | 5 | 0.95 | 0.7 | 36 | 0.35 | C |
| **数字跳跃者** | 印度c.2015, 爱沙尼亚 | 150 | 30 | 0.40 | 0.8 | 63 | 0.55 | B |
| **小型开放经济体** | 越南c.2010, 孟加拉 | 120 | 3 | 0.30 | 0.6 | 36 | 0.40 | A+C混合 |
| **后苏联工业国** | 俄罗斯, 乌克兰 | 350 | 10 | 0.85 | 1.2 | 59 | 0.40 | A |
| **人口大国弱工业** | 印度c.1990, 埃塞俄比亚 | 80 | 2 | 0.35 | 0.5 | 68 | 0.30 | A |

### 11.3 各维度的含义

**工业基础 (K_i, L_i, H_i)**：决定了渐进式积累(A)的可行性——工业足够大的国家保护才有意义。制造业大国(400)和人口大国弱工业(80)的工业资本差5倍。

**数字基础 (K_d, L_d, H_d, DL_d)**：决定了跳跃式积累(B)的起点——数字跳跃者的数字劳动力(8万)是小型开放经济体(1万)的8倍。

**资源禀赋 (R_initial)**：决定了替代式积累(C)的可行性——资源富国(0.95)几乎完全依赖资源，而小型开放经济体(0.30)几乎没有可出口的自然资源。

**人力资本 (H_avg)**：决定吸收能力和技术追赶潜力——后苏联工业国人力资本最高(1.2)，人口大国弱工业最低(0.5)。

**制度能力 (institution_capacity)**：横切所有策略的调节变量——同样选B，制度能力0.65的国家能有序反哺，制度能力0.30的国家可能失控。

**不平等 (gini_initial)**：影响政治经济学反馈环的初始状态——后苏联工业国(0.55)和资源富国(0.50)的高基尼意味着政治支持度从较低起点开始。

### 11.4 使用方式

```bash
# 列出所有国情预设
python main.py profiles

# 以制造业大国运行
python main.py demo --profile manufacturing_giant

# 以资源富国 + 技术冷战场景运行
python main.py demo --profile resource_rich

# 在代码中使用
from src.params.schema import get_schema
params = get_schema().build_from_profile(
    profile_name="digital_leapfrogger",
    regime="B",
    scenario="tech_cold_war",
)
engine = SimulationEngine(params=params, config=config, regime="B")
```

### 11.5 参数加载优先级

用户自定义覆盖（最高）→ 国际场景 → **国情预设** → 策略默认（最低）

国情预设设置的初始条件可以被国际场景或用户覆盖——例如资源富国默认制度能力为0.35，但用户可以传入 `overrides={"institution_capacity": 0.55}` 来模拟"进行了制度改革的资源富国"。

## 十二、技术架构

### 12.1 建模范式

**系统动力学(SD) + 离散事件 + SFC闭合的混合范式**。

- SD骨架处理部门间宏观反馈环和非线性动态（S曲线、门槛效应、滞后效应）
- 离散事件层处理断裂触发、泡沫破裂、外部冲击等不可微事件
- SFC核算层确保每一步的资金流动在会计上闭合（每一步验证：投资=储蓄+净借入，ΣΔ资产=ΣΔ负债）
- 代表性异质性嵌入关键节点（家庭群组、数据分层、部门内领先-落后二分），而非全面ABM

### 12.2 时间处理

- 主时间步：季度（Δt = 0.25年）
- 自适应细化：快速变化时自动缩小步长至月度或周度
- 事件驱动：断裂触发时精确记录状态快照
- 评价更新：按年计算（降低计算量）

### 12.3 技术栈

Python 3.11+ · NumPy · SciPy · Pandas · Matplotlib · h5py

参数体系：4层 ~108个参数（结构参数·策略参数·场景参数·元参数），拉丁超立方采样 + Sobol序列。

## 十七、已知局限与模型边界

一个计算模型的价值不仅在于它能产生什么结论，还在于它**知道自己的局限**。以下维度是模型在当前范式中**刻意抽象掉**或**尚未涵盖**的，使用者应在解读结论时予以注意。

### 17.1 空间与区域维度

本模型是部门间聚合模型，无空间/区域维度：
- 内陆-沿海差异、城市-农村分化、区域发展不平衡
- 劳动力跨区域流动的地理摩擦和迁移成本
- 区域间的财政转移支付

### 17.2 数字经济微观结构

数字部门作为一个聚合部门建模（不区分基础设施层/平台层/应用层）：
- 赢家通吃效应（第一名拿走大部分利润）
- 数字垄断演变为政治垄断
- 数据隐私与监控对民生安全感的影响
- 算法歧视加剧群组间就业和信贷不平等

> 已建模：网络效应（`eta_network`参数）、异质性数据资产（生产者/消费者/公共数据）

### 17.3 代际与社会结构

模型不包含内生人口动态：
- 内生生育率（高收入群组生育率下降等）
- 代际流动性（底层群组子女向上流动概率）
- 人口老龄化对劳动力供给的影响
- 社会信任与制度合法性退化机制

> 已建模：教育投资→人力资本的18年队列延迟（v3.4）

### 17.4 国际金融体系

- IMF/评级机构约束
- 资本外逃、投机攻击机制
- 债务币种结构导致的汇率风险
- 知识产权壁垒（专利/版权/出口管制）

> 已建模：荷兰病汇率渠道+支出效应、内生封锁/FDI

### 17.5 非货币福利与社会学维度

以下属于社会学和心理学范畴的维度不在当前经济学框架中：
- 就业的"尊严"维度（低端服务业vs工业的身份差异）
- 社区瓦解（工业城镇因去工业化而社会关系解体）
- 成瘾与绝望（去工业化地区药物成瘾/酗酒/自杀率上升）
- 非货币化福利（家庭自给农业、社区互助等隐性缓冲）
- 民族/种族/宗教分裂与经济冲突的交叠
- 性别维度（服务业女性化、工业男性化的结构性差异）

### 17.6 国家内部政治复杂性

国家被视为统一理性行动者，以下维度未建模：
- 竞争性官僚集团、军方、地方政府的内部拉扯
- 腐败与寻租（投资分配中的腐败截流）
- 镇压能力与公民社会的博弈（镇压vs让步的权衡）
- 政权更迭（积累策略在运行中不改变——策略是固定的输入参数）

> 已建模：群组差异化政治权重（v3.4）、政权支持度四分量反馈环（v2.2）

### 17.7 气候与环境的深层维度

气候模块已追踪碳排放和碳边境调节，以下深层维度未覆盖：
- 气候临界点（系统突变而非渐进升温）
- 环境退化的不可逆性（地下水枯竭、土壤退化无法修复）
- 气候移民（农业崩溃→城市低端服务业移民潮）
- 绿色转型的"资源诅咒2.0"（锂/钴/稀土的新依赖形式）

### 17.8 技术与生产力的极端情形

以下极端情形需单独建模：
- AI/自动化的"跳跃式替代"——临界点突然替代大量劳动力
- 通用人工智能（AGI）的质变效应
- 技术的"双用性"风险（数字基础设施被用于社会控制）
- 开源技术与技术民主化——绕过封锁的路径

### 17.9 超长时间尺度问题

100年以上时间尺度的以下问题不在模型范围内：
- 不可逆失败——崩溃后永久性落后
- 资源耗尽（淡水、耕地、关键矿产）
- 文明级"成功陷阱"——所有路径在超长尺度上走向同一结局

### 17.10 财富存量的覆盖范围

家庭群组已追踪储蓄、债务、股权和财富基尼系数（v3.4），以下维度仍未覆盖：
- 房产、境外资产等更广泛的资产类别
- 继承/代际财富转移机制
- 完整的家庭资产负债表（仅有savings/debt/equity三个字段）

---

> **方法论立场**：以上所有局限均为建模范式选择的自觉结果——覆盖它们需要的不是"更多开发时间"，而是不同的建模范式（ABM、空间一般均衡、OLG、政治学博弈论、气候系统动力学等）。一个模型的力量不来自它覆盖了多少，而来自它在既定范式内能暴露多少结构性矛盾。本模型不假装覆盖了它没覆盖的东西。
