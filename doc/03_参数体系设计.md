# 03 — 参数体系设计

## 一、参数分类体系

### 1.1 三层参数架构

```
┌─────────────────────────────────────────────┐
│ L3: 场景参数 (Scenario Parameters)            │
│ 外部环境 · 不可控 · 定义模拟的"天气"            │
│ 例子：国际技术前沿增长率、资源价格、封锁程度     │
├─────────────────────────────────────────────┤
│ L2: 策略参数 (Strategy Parameters)             │
│ 政策选择 · 可控 · 模型探索的核心维度            │
│ 例子：提取率、投资分配、再分配力度、规划强度     │
├─────────────────────────────────────────────┤
│ L1: 结构参数 (Structural Parameters)           │
│ 系统本质 · 近似不变 · 来自经验研究              │
│ 例子：资本产出弹性、折旧率、替代弹性            │
└─────────────────────────────────────────────┘
```

### 1.2 参数数量估算（v2.0）

| 层级 | 参数数量（约） | 采样策略 |
|------|-------------|---------|
| L1 结构参数 | ~55个（+15） | 大部分固定（基线值），关键参数窄范围采样 |
| L2 策略参数 | ~25个（+5） | 宽范围采样，核心探索维度 |
| L3 场景参数 | ~18个（+3） | 离散场景枚举 + 关键参数连续采样 |
| L4 元参数 | ~10个（新增） | 敏感性分析中扰动 |
| **总计** | **~108个** | 有效采样维度约18-28个 |

### 3.2 策略A：渐进积累专属参数

| ID | 符号 | 含义 | 范围 | 默认值 |
|----|------|------|------|--------|
| A01 | τ_min | 最低提取率 | [0.02, 0.10] | 0.05 |
| A02 | τ_max | 最高提取率 | [0.10, 0.30] | 0.20 |
| A03 | θ_elasticity | 提取弹性（对工业增长） | [0.1, 1.0] | 0.5 |
| A04 | safety_margin | 工业资本安全边际 | [0.5, 0.9] | 0.7 |
| A05 | φ_d_premium | 数字投资额外权重 | [0.0, 0.2] | 0.1 |

**提取率函数**（策略A的核心）：
```
τ(t) = τ_min + (τ_max - τ_min) · (g_i(t) / g_i_max)^θ_elasticity
      · safety_factor(K_i / K_i_initial)

其中 safety_factor(x) = {
    1                    if x ≥ safety_margin
    (x / safety_margin)  if x < safety_margin
}
```

**策略B的核心逻辑**：
```
阶段1（跳跃期）：
    τ_actual = min(g_target × (K_d_invest_needed / S), τ_actual_max)
    φ_d = φ_d_jump
    φ_i = 1 - φ_d_jump - φ_b_min

阶段2（反哺期）：
    触发条件：DL_d ≥ feedback_trigger
    反哺量 = feedback_ratio × Y_d
    反哺方向：工业资本更新 + 基础部门培训
```

## 五、参数采样策略

### 5.1 采样方法选择

| 方法 | 适用场景 | 优势 | 劣势 |
|------|---------|------|------|
| **拉丁超立方(LHS)** | 连续参数空间均匀覆盖 | 均匀填充，维度无关 | 不考虑参数重要性差异 |
| Sobol序列 | 高维连续空间 | 更好的低差异序列 | 实现略复杂 |
| 全因子设计 | 离散参数组合 | 全覆盖 | 组合爆炸 |
| 随机采样 | 快速粗扫 | 最简单 | 覆盖不均 |

**推荐方案**：**LHS作为主力** + **离散场景枚举** + **关键维度的Sobol敏感度分析**

### 5.2 分阶段采样策略

```
阶段1：粗扫 (Screening) — 500-1000次
    - 宽范围LHS采样所有L2参数
    - L1全固定默认值
    - 少数L3场景（3种：良性/冷战/衰退）
    目标：识别活/死边界的大致位置

阶段2：聚焦 (Focusing) — 2000-5000次
    - 在"有趣"的参数区域加密采样
    - L1关键参数（标记为"高敏感度"的）加入窄范围采样
    - 更多L3场景（5种全开）
    目标：绘制精确的临界边界

阶段3：深度 (Deep Dive) — 针对性数千次
    - 针对特定断裂模式或策略组合
    - 临界值附近的二分搜索
    - 混合策略的时间窗口扫描
    目标：回答具体的研究问题
```

### 5.3 采样实现

```python
from scipy.stats import qmc

class ParameterSampler:
    def __init__(self, schema: ParameterSchema):
        self.schema = schema

    def sample_lhs(self, n: int, param_ids: List[str]) -> np.ndarray:
        """LHS采样"""
        sampler = qmc.LatinHypercube(d=len(param_ids))
        sample = sampler.random(n=n)

        # 缩放到各参数的定义域
        for i, pid in enumerate(param_ids):
            lo, hi = self.schema.domain(pid)
            if self.schema.is_log_scale(pid):
                sample[:, i] = np.exp(
                    np.log(lo) + sample[:, i] * (np.log(hi) - np.log(lo))
                )
            else:
                sample[:, i] = lo + sample[:, i] * (hi - lo)

        return sample

    def sample_sobol(self, n: int, param_ids: List[str]) -> np.ndarray:
        """Sobol序列采样（更好的低差异序列）"""
        sampler = qmc.Sobol(d=len(param_ids), scramble=True)
        sample = sampler.random(n=n)
        # ... 同上缩放
        return sample
```

## 七、参数交互效应预判（v2.0 扩充）

基于理论分析，以下参数交互效应可能产生重要非线性：

| 参数组合 | 可能的交互效应 |
|---------|-------------|
| ν_d（吸收能力） × τ_extraction（提取率） | 提取率过高但吸收能力不足 → 浪费性积累 |
| G_critical × g_world | 追赶陷阱在"前沿慢时无关，前沿快时致命" |
| φ_d_jump × industry_tolerance | 跳跃策略的"激进-容忍"空间中的存活岛 |
| block_max × tech_import_preference | 封锁下的替代策略是否反而被迫自主 |
| α_i_dig × DL_i | 工业数字化的非线性门槛——过了某个DL_i，增益突然显著 |
| κ_diff × H_i | 知识扩散政策在人力资本高的部门更有效（← Delli Gatti 2024） |
| γ_cross × privacy_regime | 消费者数据交叉弹性在强隐私保护下被抑制（← Zhang & Wu 2025） |
| composite_dependency × G | 高数字依附下，技术差距缩小的收益被外资利润汇出抵消（← Safar Almakaty 2025） |

## 八、参数校准的学术策略

本模型的参数**不追求精确校准**——因为：
1. 许多参数在现实中无法直接观测（如"吸收能力"）
2. 模型目的不是预测，而是探索可能性空间

替代策略：
1. **合理范围锚定**：基于发展经济学文献确定参数的数量级
2. **大范围敏感性分析**：对每个关键参数，在宽范围内变化，观察结果是否稳健
3. **定性校准**：要求模型在"典型"参数下产生符合历史直觉的结果（如工业化的S曲线、中等收入陷阱等）
4. **反面校准**：能否产生已知的历史失败案例（如拉美依附、苏联解体等）？

---

**参数设计完成后的验证问题**：
1. 在默认参数下，三种策略都能至少存活一段时间吗？
2. 在极端参数下，所有策略都会崩溃吗？
3. 是否存在参数区域，策略排序反转？
4. 最敏感的参数是否在理论上合理？（不该是"数据折旧率"这种次要参数）
