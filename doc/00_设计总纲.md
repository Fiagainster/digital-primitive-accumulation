# 00 — 设计总纲（v2.2 · 政治经济学反馈环）

> **版本历史**：v2.0 (基础架构) → v2.1 (断裂级联+知识扩散) → v2.2 (EWS韧性+政治反馈+数字密度)

## 一、项目定位再确认

本项目的输出物不是一个"预测某个国家会怎样"的预测模型，而是一个**机制揭示系统（Mechanism-Revealing System）**。它的核心任务可以概括为四句话：

1. **给定初始条件和策略规则，在时间维度上展开三部门互动**
2. **记录所有状态变量的完整轨迹，不做任何先验的"好/坏"判断**
3. **识别断裂模式的触发条件和临界阈值——包括事前预警而非仅事后诊断**
4. **刻画代价的时空分布与可补偿性——将代价定位到可识别的社会群体**

> 关键原则：**模型的价值不在于"答案正确"，而在于"暴露我们不知道的东西"**。如果模型产生了反直觉的结果，那正是最有价值的发现。

## 二、核心设计决策

### 决策1：建模范式 → 系统动力学 + 离散事件混合（+ SFC闭合约束）

| 候选范式 | 优势 | 劣势 |
|---------|------|------|
| 纯系统动力学(SD) | 连续方程，适合宏观反馈 | 难以表达离散事件，会计恒等式可能不闭合 |
| 纯Agent-Based(ABM) | 异质性个体，涌现行为 | 计算量巨大，参数校准困难 |
| **SD + 离散事件 + SFC混合(选定)** | 连续动态 + 离散断裂 + 会计闭合 | 实现复杂度较高 |

**选择理由**：
- SD骨架处理部门间宏观反馈环和非线性动态
- 离散事件层处理断裂触发
- **SFC核算层确保每一步的资金流动在会计上闭合**（← Jackson & Jackson 2025 TranSim 2; Dafermos & Nikolaidi DEFINE）
- 关键位置嵌入代表性异质性（异质性家庭群组、数据分层、部门内领先-落后二分），而非全面ABM（← Dosi & Roventini 2024）

### 决策2：时间处理 → 离散时间步（年/季）+ 事件驱动的子步

- **主时间步**：以季度为基本单位（步长 Δt = 0.25 年），模拟周期 50-100 年
- **自适应细化**：当检测到快速变化（如断裂逼近），自动缩小步长至月度甚至周度
- **事件驱动**：断裂触发时，在触发时刻精确记录状态快照
- **EWS滑动窗口**：每步基于最近20-50个观测窗口计算早期预警统计量（← Scheffer临界慢化理论）

### 决策3：参数处理 → 分层参数体系（四层）

将所有参数分为四层：

- **L1 — 结构参数**：刻画系统本质特征（资本产出弹性、折旧率、替代弹性等），来自经验研究，在单次模拟中固定
- **L2 — 策略参数**：刻画政策选择（提取率、投资分配比例、知识扩散政策力度等），是探索的核心维度
- **L3 — 场景参数**：刻画外部环境（国际价格、技术前沿增长率、封锁程度等），定义模拟的边界条件
- **L4 — 元参数**：控制模型行为本身的参数（断裂阈值、EWS窗口长度等），在敏感性分析中扰动

### 决策4：实现语言 → Python + 科学计算栈

- **核心引擎**：Python（NumPy + SciPy + Numba JIT加速）
- **批量模拟**：multiprocessing 或 Ray 进行参数空间并行探索
- **数据管理**：HDF5（h5py）存储大规模模拟结果
- **分析可视化**：Pandas + Matplotlib/Plotly + 自定义分析模块
- **非线性动力学分析**：自定义分岔检测 + 可选BifurcationKit调用

### 决策5：核算原则 → SFC（存量-流量一致）

> 每一笔支出都是另一方的收入。每一笔资产都是另一方的负债。

模型在每一步确保：
- 投资 = 储蓄 + 净借入（部门层面）
- ΣΔ金融资产 = ΣΔ金融负债（宏观闭合）
- 总产出 = 总收入 = 总支出（三面等价）

**如不闭合**：通过"未计划库存变化"或"意外储蓄/负储蓄"吸收残差——这是真实世界宏观经济数据中确实存在的项目。

### 4.2 模块间依赖关系（v2.0）

```
parameters (被所有模块依赖)
    ↓
engine ← coupling ← sectors
    ↓
sfc ← accumulation, international  (SFC闭合层在资金分配之后)
    ↓
data_assets, digitalization, technology, technology_diffusion
    ↓
digital_dependency, households, deindustrialization  (异质性追踪层)
    ↓
welfare, cost  (福利与代价取决于异质性追踪)
    ↓
fracture ← ews  (EWS在断裂检测之前运行)
    ↓
recorder
    ↓
experiment → analysis (含分岔分析)
```

原则：**单向依赖，无循环**。`engine` 是唯一的调度中心。新增的SFC层在资金分配后运行，确保会计闭合。EWS在断裂检测之前运行，提供事前预警。

## 五、关键创新点设计（v2.0）

### 5.1 SFC核算框架（← Jackson & Jackson TranSim 2; Dafermos DEFINE）

```python
class SFCClosure:
    """每一步确保会计恒等式成立"""

    def check_and_close(self, state, transaction_matrix, balance_sheets):
        # 1. 验证资金流动净额为零（谁支出谁收入）
        # 2. 验证 Δ资产 = Δ负债 + Δ净资产
        # 3. 如不闭合，通过"未计划库存变化"吸收残差
        residual = self.compute_residual(transaction_matrix)
        if abs(residual) > tolerance:
            self.absorb_residual(residual, via="unplanned_inventory")
```

### 5.2 异质性代价追踪（← EUROGREEN异质性家庭）

代价不再是一个聚合数，而是可定位到四个家庭群组的具体损失：

```python
class CostTracker:
    def track_by_group(self, state, prev_state):
        for group in [HIGH_SKILL_DIGITAL, INDUSTRIAL_WORKERS,
                       BASE_WORKERS, UNEMPLOYED]:
            self.costs[group].unemployment_years += ...
            self.costs[group].wage_loss += ...
            self.costs[group].skill_depreciation += ...
            self.costs[group].cumulative_cost += ...

        # 群体间代价比：工业劳动者代价 / 数字劳动者代价
        self.cost_ratio = self.costs[INDUSTRIAL_WORKERS] / self.costs[HIGH_SKILL_DIGITAL]
```

### 5.3 早期预警信号系统（← Scheffer临界慢化; PNAS 2025爆炸同步）

```python
class EarlyWarningMonitor:
    """
    检测系统逼近临界点的统计信号。
    这回答了"什么时候转向还来得及"——在断裂触发之前。
    """
    def compute_ews(self, variable, window=40):
        return EWSResult(
            variance_trend=self._kendall_tau(rolling_variance),
            ar1_trend=self._kendall_tau(rolling_ar1),
            flickering=self._detect_bimodality(variable[-window:]),
            skewness=stats.skew(variable[-window:]),
            explosive_sync_proximity=self._es_index(coupling_strength)
        )
```

区分三种去工业化：正常（高技能吸收）、过早（退回低端服务）、跳跃诱发（策略B过度提取）。

## 六、设计哲学总结（v2.0）

1. **分离关注点**：机制与策略严格分开；核算与行为严格分开
2. **非线性优先**：线性关系不会产生意外发现；S曲线、门槛效应、滞后效应、正反馈是核心
3. **全状态记录**：不只看终点，要看全过程 + 全过程EWS统计量
4. **代价可见且可定位**：让隐性的代价变得可度量、可定位到具体社会群体、可追溯
5. **会计闭合**：每一分钱的来龙去脉都有交代（SFC原则）
6. **事前预警而非仅事后诊断**：在断裂触发之前就检测到系统正在失去恢复力
7. **可复现性**：任何一次模拟的初始条件+参数+随机种子 → 可精确复现
