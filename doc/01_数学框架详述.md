# 01 — 数学框架详述（v2.0 · 整合前沿研究）

## 一、符号约定

### 1.1 部门下标

- `b` — 基础部门 (Base)：农业、资源开采、低端制造
- `i` — 工业部门 (Industry)：制造、建筑、硬件生产
- `d` — 数字部门 (Digital)：软件、数据服务、AI
- `j ∈ {b, i, d}` — 泛指任一部门

### 1.2 家庭群组下标（新增）

- `h_d` — 数字部门高技能劳动者 (high-skill digital)
- `h_i` — 工业劳动者 (industrial workers)
- `h_b` — 基础部门劳动者 (base workers)
- `h_u` — 失业者 (unemployed)

### 1.3 时间符号

- `t` — 时间（单位：年）
- `Δt` — 离散时间步长（基础步长 0.25 年）
- `X(t)` — 变量 X 在时刻 t 的值
- `Ẋ` 或 `dX/dt` — X 对时间的导数
- `⟨X⟩_W` — X 在窗口 W 内的滑动均值

## 二、生产函数的形式化（v2.0 数据异质性升级）

### 2.1 通用结构

```
Y_j = A_j · F_j(K_j, H_j, L_j) · DIG_j(DL_j, DS_j) · RES_j(·)
```

### 2.2 基础部门

```
Y_b = A_b · [θ_b·K_b^((σ_b-1)/σ_b) + (1-θ_b)·(H_b·L_b)^((σ_b-1)/σ_b)]^(σ_b/(σ_b-1))
      · (1 + α_b · DL_b^β_b)
      · (R/R_0)^λ_b
```

### 2.3 工业部门（新增：知识扩散增强）

```
Y_i = A_i · K_i^α_i · (H_i·L_i)^(1-α_i)
      · (1 + α_i_dig · DL_i^β_i_dig)
      · (DS_i / K_i)^γ_i
      · min(1, M_avail / M_needed)^μ_i
      · (1 + κ_diff_i · TechDiffusionGap_i)
```

其中新增项 `TechDiffusionGap_i` 刻画数字技术向工业的扩散程度：

```
TechDiffusionGap_i = (A_d / A_i - 1) · diffusion_rate_i
diffusion_rate_i = spontaneous_diff + κ_diff · policy_effectiveness_i
```

- `spontaneous_diff`：通过市场机制的自然扩散（人员流动、供应链学习）
- `κ_diff`：知识扩散政策力度（新增策略参数，← Delli Gatti et al. 2024）
- `policy_effectiveness_i`：目标部门的政策吸收效率

### 2.4 数字部门（v2.0 数据异质性升级）

```
Y_d = A_d · K_d^α_d · (H_d·L_d)^(1-α_d)
      · (HW_d / K_d)^δ_d
      · (Data_effective / Data_0)^ε_d
      · (1 + η_d · NetworkEffect(Users_d))
```

**异质性数据存量**（← Zhang & Wu 2025）：

```
Data_effective = Data_prod · (1 + γ_cross · Data_cons) + Data_pub · (1 + δ_open)
```

三种数据分别积累：

```
d(Data_prod)/dt = φ_prod · Y_i · DL_i - δ_prod · Data_prod
    # 工业数字化过程产生生产者数据（IoT、传感器、供应链）

d(Data_cons)/dt = φ_cons · C_digital · penetration_rate - δ_cons · Data_cons
    # 数字消费行为产生消费者数据（平台、支付、社交）

d(Data_pub)/dt = φ_pub · Gov_R&D - δ_pub · Data_pub
    # 公共研发和统计产生公共数据
```

**数据交互效应**：
- `γ_cross`：消费者数据对生产者数据的交叉增强（用户行为数据帮助优化生产）
- `δ_open`：公共数据的开放性红利

**不同数据的制度约束不同**：
- 消费者数据受隐私法规限制 → `δ_cons` 在强隐私保护下更高
- 生产者数据受商业机密保护 → 共享程度取决于制度
- 公共数据默认可开放 → 但需要公共投资维持

## 三、SFC核算框架的形式化（新增）

### 3.1 交易流矩阵

每个时间步，所有部门间的资金流动必须满足：

```
Σ_i 收入_i = Σ_i 支出_i （对每个交易类别）
```

| 交易 | 基础部门 | 工业部门 | 数字部门 | 家庭 | 政府 | 国外 | Σ |
|------|---------|---------|---------|------|------|------|---|
| 消费 | +C_b | +C_i | +C_d | -C_total | -C_gov | | 0 |
| 投资 | +I_b | +I_i | +I_d | | -I_gov | | =S |
| 工资 | -W_b·L_b | -W_i·L_i | -W_d·L_d | +W_total | | | 0 |
| 税收 | -T_b | -T_i | -T_d | -T_h | +T_total | | 0 |
| 转移支付 | | | | +Transfers | -Transfers | | 0 |
| 进出口 | +X_b | +X_i | +X_d | | | -M_total | =NX |
| **净金融余额** | ΔFA_b | ΔFA_i | ΔFA_d | ΔFA_h | ΔFA_gov | ΔFA_row | 0 |

### 3.2 部门资产负债表

```
对于每个部门 j：

资产：
  K_j(t+Δt) = K_j(t) + I_j_actual·Δt - δ_j·K_j·Δt - ω_j·Δt
  FA_j(t+Δt) = FA_j(t) + ΔFA_j·Δt
  Data_j(t+Δt) = Data_j(t) + (生成 - 折旧)·Δt

负债：
  Debt_j(t+Δt) = Debt_j(t) + (新借入 - 偿还)·Δt

净资产：
  NW_j = K_j + FA_j + Data_j - Debt_j

恒等式：
  ΔNW_j = 储蓄_j = 收入_j - 支出_j
```

### 3.3 SFC闭合条件

```
每一步检验：
1. Σ ΔFA = 0     （金融资产净发行之和为零）
2. I_total = S_total + NX + (G - T)   （投资=储蓄会计恒等式）
3. 若1和2不满足在容差范围内：
   → 调整"未计划库存变化" ΔInventories_unplanned
   → 或调整"意外储蓄" S_unexpected
   → 记录残差大小作为诊断指标
```

**为什么需要SFC**：没有SFC框架，模型可能在无意识中"从空气里变出资本"或"价值凭空消失"——这会严重损害模型在学术上的可信度。

### 5.3 去工业化质量诊断（新增 ← Rodrik 2016; Zhu et al. 2025）

```
当 dL_i/dt < 0（工业劳动力减少）：

流出劳动力去向：
  flow_i→d：转入数字部门
  flow_i→b：转回基础部门
  flow_i→u：失业

去工业化类型判定：

IF (flow_i→d / |dL_i| > 0.5) AND (W_i > W_i_prev):
    deind_type = NORMAL
    # 工业工资上升，高技能劳动力转移到数字部门——正常的结构转型

ELIF (flow_i→b / |dL_i| > 0.5) AND (W_i < W_i_prev):
    deind_type = PREMATURE
    # 工业工资下降，劳动者被迫返回低端服务业——过早去工业化

ELIF (flow_i→u / |dL_i| > 0.3):
    deind_type = COLLAPSE
    # 大量直接失业——工业崩溃型去工业化

ELIF (K_i / K_i_initial < 0.5) AND (τ_extraction > τ_normal):
    deind_type = DIGITAL_LEAP_INDUCED
    # 策略B过度提取导致的工业萎缩

ELSE:
    deind_type = MIXED
```

**去工业化质量指数**：

```
DeindQuality = f(去向分布, 工资变化, 技能匹配度, 再就业率)
```

## 七、早期预警信号(EWS)的形式化（新增）

### 7.1 临界慢化检测（← Scheffer et al.）

对每个关键监测变量 X，在滑动窗口 W（长度 N=20~50步）内计算：

```
# 1. 方差上升 — 系统对扰动越来越敏感
Var_W(t) = (1/N) · Σ_{k=0}^{N-1} (X(t-k·Δt) - ⟨X⟩_W)^2
Kendall_τ_Var = τ(Var_W(t), Var_W(t-1), ..., Var_W(t-M))
    # 方差的Kendall趋势检验——方差是否在系统性上升？

# 2. 自相关上升 — 恢复速度变慢（临界慢化的核心信号）
AR1_W(t) = Corr(X(t), X(t-Δt))  在窗口W内
Kendall_τ_AR1 = τ(AR1_W(t), ..., AR1_W(t-M))

# 3. 偏度变化 — 不对称波动
Skew_W(t) = E[(X - ⟨X⟩_W)^3] / σ_W^3
    # 负偏度增大 → 系统更容易向下跳变

# 4. 闪烁(Flickering) — 在两种状态间快速跳跃
Bimodality_W(t) = Hartigan's Dip Test p-value
    # 低p值 → 分布呈双峰 → 系统在两个吸引子间闪烁
    # 参考Gatfaoui & de Peretti (2019) Scientific Reports
```

### 7.2 爆炸同步接近度（← PNAS 2025）

```
# 部门间耦合强度是否接近"爆炸同步"临界点？
ES_proximity(t) = (κ_coupling(t) - κ_c) / κ_c

其中 κ_coupling = Σ_{j≠k} |∂Y_j/∂X_k|  # 部门间耦合的Jacobian范数
     κ_c = 临界耦合强度（通过多次模拟的经验分布估计）
```

### 7.3 综合EWS指数

```
Composite_EWS(t) = w_1 · Kendall_τ_Var
                 + w_2 · Kendall_τ_AR1
                 + w_3 · |Skew_W(t) - Skew_baseline|
                 + w_4 · (1 - Bimodality_pvalue)
                 + w_5 · max(0, ES_proximity(t))

EWS状态判定（带滞后以避免频繁切换）：
  EWS_NORMAL:   Composite_EWS < 0.4
  EWS_WARNING:  0.4 ≤ Composite_EWS < 0.7
  EWS_CRITICAL: Composite_EWS ≥ 0.7
```

### 7.4 EWS监测的变量-断裂对应表

| 监测变量 | 对应断裂风险 | 最敏感EWS指标 |
|---------|-------------|-------------|
| K_i / K_i(0) | 工业枯萎 | 方差↑ + AR(1)↑ |
| G = A_world/A_d | 技术锁死 | AR(1)↑ + 偏度→负 |
| TechImport_share | 依附固化 | 闪烁（自主/进口间跳跃） |
| 失业率 | 社会崩溃 | 方差↑ + 偏度→正 |
| 福利指数 | 社会崩溃 | 偏度→负 |
| 部门耦合强度 | 系统级崩溃 | 爆炸同步接近度 |

## 八、异质性家庭与代价的形式化（v2.0 升级）

### 8.1 四个家庭群组

```
每个群组 h ∈ {h_d, h_i, h_b, h_u}：

人口动态：
  d(Pop_h)/dt = 流入_h - 流出_h + 自然增长_h

收入：
  Income_h = Wage_h · Employed_h + Transfers_h + CapitalIncome_h

消费：
  C_h = mpc_h · Income_h + autonomous_consumption_h

福利：
  Welfare_h = f(人均消费_h, 就业率_h, 健康水平_h, 教育水平_h)

累计代价：
  CumulativeCost_h(t) = ∫(工资损失_h + 技能贬值_h + 迁徙成本_h + 心理成本_h) dτ
```

### 8.2 群体间代价比

```
代价集中度 = Gini({CumulativeCost_h / Pop_h})

代价比_h_vs_d = CumulativeCost_i（工业劳动者）/ CumulativeCost_d（数字劳动者）

# 这个比值直接回答了"谁承受了代价"：
# → 比值 >> 1：工业劳动者承受了远超数字劳动者的代价
# → 比值 ≈ 1：代价均匀分担
# → 比值 < 1：数字劳动者承受更多（反直觉场景——可能发生在技术泡沫破裂时）
```

### 8.3 群体政治影响力与补偿分配

```
# 政治影响力影响补偿的分配（而不仅仅是"需要"）
PoliticalPower_h = f(Pop_h, Income_h, 组织程度_h, 历史地位_h)

# 实际补偿分配 = 需要驱动的分配 × 影响力调整
Compensation_h = Comp_needed_h · (1 + λ_power · PoliticalPower_h)

# λ_power = 0：纯需要驱动（技术官僚理想）
# λ_power > 0：政治博弈影响分配（现实主义）
```

```

1.  更新外生变量
```
