# 04 — 模拟实验设计

## 一、实验总体框架

### 1.1 实验金字塔

```
                   ┌─────────┐
                   │ 深度分析  │  ~10个专题实验
                   ├─────────┤
                   │ 聚焦探索  │  ~5个聚焦实验 × 5场景
                   ├─────────┤
                   │ 粗扫筛选  │  ~3个粗扫实验 × 3场景
                   └─────────┘
```

### 1.2 实验编号体系

每个实验有唯一ID：`EX-{层}-{序号}-{场景缩写}`

- 层：`S`(粗扫)、`F`(聚焦)、`D`(深度)
- 场景缩写：`BG`(良性全球化)、`TC`(技术冷战)、`RC`(资源崩溃)、`TB`(技术爆发)、`GR`(全球衰退)

## 二、第一层：粗扫实验（Screening）

### EX-S-01：基准生存扫描

**目标**：找到三种纯策略的"生存边界"

**参数设置**：
- L1 结构参数：全部固定为默认值
- L2 策略参数：
  - 策略A 5个参数：LHS采样 500组
  - 策略B 7个参数：LHS采样 500组
  - 策略C 6个参数：LHS采样 500组
- L3 场景：良性全球化(BG)
- 每次模拟：T_max=100年，基础初始条件

**总计**：1500次模拟

**输出**：
- 每种策略的存活率
- 存活/崩溃的参数边界粗略图
- 主要断裂模式分布

### EX-S-02：初始条件扫描

**目标**：探索初始条件对策略存活的影响

**参数设置**：
- L2 策略参数：固定为各策略的"中等"值
- L1 结构参数：固定默认值
- IC 初始条件：
  - `K_i_initial`：3个离散水平
  - `K_d_initial`：3个离散水平
  - `H_avg_initial`：3个离散水平
  - `R_initial`：3个离散水平
  - 全因子 = 81种组合
- L3 场景：BG
- 每种策略 81次 = 243次

**输出**：
- 初始条件的"可行域"——在什么初始条件下有存活策略
- 最关键的初始条件维度

### EX-S-03：场景冲击扫描

**目标**：同一策略在不同国际场景下的存活差异

**参数设置**：
- L2 参数：中等值
- 5种场景 × 3种策略 × 5个初始条件组合 = 75次
- 每个场景扫200组L2参数 = 5×3×200 = 3000次

**总计**：~3000次

**输出**：
- 策略的场景稳健性排名
- "场景依赖性"——哪些策略严重依赖特定国际环境

## 三、第二层：聚焦实验（Focusing）

### EX-F-01：断裂临界边界的精确绘制

**目标**：在粗扫发现的"活/死边界"附近加密采样

**方法**：
1. 从粗扫结果中识别崩溃/存活的分界面
2. 用二分搜索沿分界面法线方向精确搜索临界参数值
3. 对每条断裂路径，绘制参数空间中的临界曲面

**参数**：以 EX-S-01 结果为指导，选取最敏感的3-5个参数
**规模**：每维度50点 × 2维度 × 3策略 × 3场景 ≈ 22500次

**输出**：
- 各断裂模式的临界参数值（表格）
- 参数空间相图（2D切片）
- 临界曲面的3D可视化

### EX-F-02：跳跃策略的"反哺窗口"分析

**目标**：系统扫描策略B中反哺机制的可行性

**参数扫描**：
- `feedback_trigger`（反哺触发阈值）：[0.3, 0.8]，步长0.05
- `feedback_ratio`（反哺比例）：[0.05, 0.40]，步长0.05
- `industry_tolerance`（工业容忍度）：[0.2, 0.8]，步长0.05
- 时间维度：记录反哺窗口的开启时间和关闭时间

**规模**：11×8×13 × 1场景 = 1144次（全因子）

**输出**：
- 反哺窗口存在/不存在的参数区域
- 窗口宽度（年数）的热力图
- "错过窗口"的频率和后果

### EX-F-03：技术追赶的临界条件

**目标**：找到"追赶"与"锁死"的参数边界

**参数扫描**：
- `g_world`：[0.01, 0.12]（前沿增长率范围）
- `χ_d`（吸收系数）：[0.02, 0.20]
- `ζ_d`（自主创新系数）：[0.01, 0.10]
- `G_critical`（陷阱临界差距）：[3, 20]
- LHS采样：5000组

**规模**：5000次 × 3策略 × 2场景(BG, TB) = 30000次

**输出**：
- 追赶成功/失败在参数空间中的分布
- 追赶陷阱的"吸引力盆地"大小
- 自主创新vs技术吸收的最优混合比例

### EX-F-04：代价分布与策略选择

**目标**：系统比较不同策略下的代价分布模式

**参数扫描**：
- 每种策略500组L2参数 × 3个IC组合 = 1500次
- 每个模拟全程记录代价指标时间序列

**规模**：3策略 × 1500 = 4500次

**输出**：
- 代价基尼系数的策略间比较
- "高代价群体"的识别（哪类劳动者承受最多代价）
- 补偿窗口存在概率和宽度分策略统计

### EX-F-05：混合策略的时间窗口扫描

**目标**：寻找最优的策略切换时机

**参数扫描**：
- 策略序列：A→B, B→A, A→C, C→A, B→C, C→B（6种）
- 切换时间 `t_switch`：[5, 50]年，步长5年
- 过渡期长度：[2, 10]年，步长2年

**规模**：6 × 10 × 5 × 2场景 = 600次（全因子）

**输出**：
- 最优切换序列和时机
- 混合策略是否显著优于纯策略
- 切换成本与收益的量化比较

### EX-F-06：EWS预警有效性验证（v2.0 新增）

**目标**：验证EWS系统是否能在断裂触发前提供有效预警

**方法**：
1. 从EX-S-01结果中选取所有最终断裂的模拟
2. 回放这些模拟的完整时间序列，计算EWS信号
3. 统计：EWS_WARNING首次出现时间 vs 断裂触发时间
4. 计算预警提前量 = t_fracture - t_first_warning

**规模**：取决于EX-S-01的结果，预计分析~500-1000个断裂案例

**输出**：
- EWS预警提前量分布（均值、中位数、最小值）
- EWS误报率（EWS_WARNING但最终未断裂的比例）
- EWS漏报率（断裂前从未发出WARNING的比例）
- 各EWS指标（方差、AR(1)、闪烁、爆炸同步）的相对重要性
- "黄金窗口"——从首次预警到断裂的可用响应时间

### EX-F-07：数字依附的多维路径分析（v2.0 新增）

**目标**：探索数字依附的不同维度如何交互影响发展路径

**参数扫描**：
- `infrastructure_dependency`：[0.1, 0.9]，步长0.1
- `data_dependency`：[0.1, 0.9]，步长0.1
- `standards_autonomy`：[0.1, 0.9]，步长0.1
- 策略C的参数在"中等"水平

**规模**：9×9×9 × 3场景 = 2187次（全因子）

**输出**：
- "依附安全区"——哪些维度可以依赖而不触发依附固化断裂
- 依附维度的替代性——某个维度自主能否补偿另一维度的依附
- 策略C下从"依附"到"自主"的转型窗口

## 四、第三层：深度分析实验（Deep Dive）

### EX-D-01：反直觉发现的验证与机制追踪

**触发条件**：当粗扫或聚焦实验产生反直觉结果时

**方法**：
1. 在反直觉区域的参数点进行密集模拟（50-100次）
2. 打开全部状态记录，逐时间步追踪因果链
3. 使用因果追踪算法识别关键机制链条

**输出**：
- 反直觉结果的机制解释
- 产生反直觉结果的必要条件

### EX-D-02：代价的时空动态追踪

**目标**：追踪代价如何在时间、空间、群体间传递和转化

**方法**：
- 选取10个代表性参数组合
- 启用"个体追踪"模式（在聚合模型中加入代表性个体群组）
- 记录每个群组在整个模拟周期中的福利变化

**输出**：
- 代价传递的"瀑布图"
- 代价在不同群体间的转换（如：工业失业 → 基础部门压低工资 → 基础部门受损）
- 代价遗留的持续时间

### EX-D-03：制度变量的调节效应

**目标**：量化制度（再分配、规划、社保）对策略效果的调节

**参数扫描**：
- τ_w（再分配力度）：[0, 0.5]，步长0.05
- κ（规划强度）：[0, 1.0]，步长0.1
- social_coverage（社保覆盖率）：[0, 1.0]，步长0.1
- 在3种策略×3种场景下全因子

**规模**：11×11×11 × 9组合 = 11979次

**输出**：
- 制度的"拯救效应"——哪些制度能扭转崩溃
- 制度的边际收益递减点
- "制度替代"效应——某些制度组合可以替代策略选择

### EX-D-04：多维断裂的交叉效应

**目标**：研究多种断裂模式同时逼近时的交互效应

**方法**：
- 从聚焦实验中识别"多断裂并发"的参数区域
- 在这些区域进行密集采样
- 分析断裂的先后次序——哪种断裂先触发？先触发的是否加速了后续断裂？

**输出**：
- 断裂级联的模式
- "安全走廊"——在多种断裂夹缝中存活的窄参数路径

### EX-D-06：EWS驱动的策略自适应切换（v2.0 新增）

**目标**：测试基于EWS信号自动调整策略是否能提高存活率

**方法**：
- 设计"自适应策略"：当Composite_EWS超过warning阈值时，自动调整策略参数（降低提取率、增加反哺、增加知识扩散投入）
- 与固定策略比较存活率和代价分布

**规模**：500组L2参数 × 3场景 ×（3固定策略 + 1自适应策略）= 6000次

**输出**：
- EWS驱动的自适应策略是否能显著提高存活率
- 自适应策略的"调整成本"——频繁调整是否带来额外代价
- 最优的自适应规则参数（何时调整、调整多少）

### EX-D-05：极端场景的极限测试

**目标**：测试模型在极端参数下的行为

**场景包括**：
- 国际技术彻底封锁（block_max = 1.0）
- 资源瞬间枯竭（R → 0）
- 人口断崖（劳动力年减5%）
- AI奇点（g_world → 0.50）
- 多重冲击叠加

**规模**：~500次定向测试

**输出**：
- 系统的绝对崩溃条件
- 在极端条件下"存活"所需的最低条件

## 五、敏感性分析体系

### 5.1 全局敏感性：Sobol指数

针对每种策略-场景组合，计算每个参数对关键输出的一阶和总效应Sobol指数。

```
关键输出变量：
1. 是否存活（二元）
2. 存活时间（连续）
3. 最终技术差距
4. 峰值代价基尼系数
5. 累计总产出

Sobol分析规模：
- 每个策略-场景组合：N×(2D+2)次模拟
- N=1024（基准样本量），D=15（有效维度数）
- = 1024 × 32 = 32768次/组合
- 3策略 × 3场景 = 9组合
- 总计 ~295,000次
```

> 注：这个规模较大，建议在聚焦实验确定"有趣"区域后再进行。可以在较窄的参数范围内进行Sobol分析以降低所需样本量。

### 5.2 局部敏感性：基准点扰动

在基准参数点附近，逐个参数 ±10% 扰动，观察输出变化：

```
基准参数集 = 默认值
对每个参数：
    模拟(参数 = 默认 × 1.1)
    模拟(参数 = 默认 × 0.9)
    计算弹性 = Δ输出 / Δ参数

规模：~75参数 × 2扰动 = 150次/策略/场景
```

## 六、结果解读框架

### 6.1 实验报告模板

每个实验完成后，按以下结构输出：

```
1. 实验摘要
   - 模拟次数、存活率、主导断裂模式
   
2. 参数空间地图
   - 存活/崩溃在参数空间中的分布（2D投影）
   - 临界边界的位置和形状
   
3. 断裂模式谱系
   - 各断裂模式的频率和条件
   - 断裂的时序模式（哪种先来）
   
4. 代价分布
   - 代价的集中度、主体分布、时间分布
   - 补偿窗口统计
   
5. 策略比较
   - 策略在多个维度上的排名
   - 策略的稳健性评分
   
6. 意外发现
   - 反直觉的结果
   - 需要进一步探索的现象
```

### 6.2 解读的政治经济学映射

将数值结果映射回政治经济学命题：

| 数值发现 | 政治经济学含义 |
|---------|-------------|
| 所有策略在大部分空间崩溃 | 数字时代的原始积累可能没有可行路径 |
| 策略排序随参数反转 | 没有普适最优策略，依赖历史条件 |
| 混合策略显著优于纯策略 | 时机和节奏比方向更重要 |
| 代价高度集中 | 任何策略必须配套补偿制度 |
| 某些参数存在临界阈值 | 存在"不可逆点"，必须在此之前调整 |
| EWS预警提前量足够但未被利用 | **制度必须建立对预警信号的响应机制**（v2.0新增） |
| 数据依附比基础设施依附更难摆脱 | **数据主权比硬件自主更紧迫**（v2.0新增） |
| 知识扩散政策弥补R&D补贴的无效 | **产业政策必须双轨制**（v2.0新增） |

## 七、实验执行优先级

考虑到计算资源的限制，建议按以下优先级执行：

**第一优先**（必须完成）：
1. EX-S-01：基准生存扫描 — 建立基本认知
2. EX-S-03：场景冲击扫描 — 了解场景依赖性
3. EX-F-04：代价分布 — 核心创新
4. EX-F-06：EWS预警有效性验证 — v2.0核心创新

**第二优先**（高价值）：
5. EX-F-01：断裂临界边界 — 理论核心
6. EX-F-02：反哺窗口 — 策略B的关键问题
7. EX-F-03：技术追赶临界 — 技术维度的核心
8. EX-F-07：数字依附多维路径 — v2.0新增

**第三优先**（锦上添花）：
9. EX-F-05：混合策略 — 可能产生最重要发现
10. EX-D-03：制度调节效应 — 政策含义
11. EX-D-06：EWS自适应策略 — v2.0新增

**按需触发**：
- EX-D-01：反直觉验证 — 当发现反直觉结果时
- 敏感性分析 — 在确定关键参数区域后
