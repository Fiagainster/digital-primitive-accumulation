# 05 — 实现路线图

## 一、总体开发哲学

### 1.1 渐进构建原则

```
不要一次构建整个系统。
先构建最小的可运行内核，验证核心机制，再逐层叠加复杂度。

        阶段4: 完整实验室
       ┌──────────────┐
       │ 阶段3: 分析工具 │
     ┌──────────────┐  │
     │ 阶段2: 完整引擎│  │
   ┌──────────────┐  │  │
   │阶段1: 最小内核│  │  │
   └──────────────┘  │  │
     └──────────────┘  │
       └──────────────┘
```

### 1.2 每个阶段的验证标准

每个阶段结束时，必须满足：
1. **可运行**：能够从命令行启动并产生有意义输出
2. **可检验**：有测试用例验证核心逻辑
3. **可理解**：输出可视化的、人类可解读的结果
4. **可复现**：相同的输入产生相同的输出（确定性随机种子）

## 三、阶段1：最小可运行内核（Week 3-5）

### 目标
实现**单一部门**的简化模型，验证核心循环和数值求解的可行性

### 3.1 简化假设

```
阶段1简化：
- 仅有工业部门（单部门）
- 无劳动力流动（L固定）
- 无数字化（DL=0）
- 无国际交互（封闭经济）
- 无断裂检测
- 生产函数：Cobb-Douglas，Y = A · K^α · (H·L)^(1-α)
- 资本积累：dK/dt = s·Y - δ·K
- 固定储蓄率 s
```

### 3.2 任务清单

| # | 任务 | 输出 |
|---|------|------|
| 1.1 | 部门基类 | `models/base_sector.py` — 抽象接口 |
| 1.2 | 简化工业部门 | 仅Cobb-Douglas + 资本积累 |
| 1.3 | 模拟引擎主循环 | `core/engine.py` — 时间推进、调用部门step() |
| 1.4 | Euler/RK4求解器 | 数值积分，步长控制 |
| 1.5 | 基础可视化 | 时间序列折线图（K, Y, W随时间变化） |
| 1.6 | 单元测试 | 验证解析解vs数值解（对简化模型解析解已知） |
| 1.7 | 命令行入口 | `python -m src --config config.yaml` |

### 3.3 验证

```
测试1：无技术进步
  Y = K^0.4 · L^0.6, s=0.2, δ=0.05
  → 应收敛到稳态 K* = (s·A/δ)^(1/(1-α)) · L
  → 验证数值解在100年后在稳态1%以内

测试2：外生技术进步
  A(t) = A_0 · exp(g·t), g=0.02
  → 应沿平衡增长路径，K/Y比率恒定
  → 验证增长率收敛到 g/(1-α)

测试3：步长敏感性
  在 dt = 0.25, 0.1, 0.05, 0.01 下运行
  → 100年后K的差异应在0.1%以内
```

## 附件：最小可运行内核伪代码

```python
# stage1_minimal.py — 最简可运行版本（单部门，< 100行）

import numpy as np
from dataclasses import dataclass

@dataclass
class Params:
    A: float = 1.0       # 技术水平
    alpha: float = 0.4    # 资本产出弹性
    s: float = 0.2        # 储蓄率
    delta: float = 0.05   # 折旧率
    L: float = 100.0      # 劳动力（固定）
    H: float = 1.0        # 人力资本（固定）

@dataclass
class State:
    K: float              # 资本存量
    t: float = 0.0

    @property
    def Y(self) -> float:
        return Params.A * self.K**Params.alpha * (Params.H * Params.L)**(1 - Params.alpha)

    @property
    def W(self) -> float:
        return (1 - Params.alpha) * self.Y / Params.L  # 边际产出

    @property
    def r(self) -> float:
        return Params.alpha * self.Y / self.K - Params.delta

def simulate(K0: float, T: float = 100, dt: float = 0.25):
    state = State(K=K0)
    ts, Ks, Ys = [], [], []

    while state.t < T:
        ts.append(state.t)
        Ks.append(state.K)
        Ys.append(state.Y)

        # Euler步进
        dK = Params.s * state.Y - Params.delta * state.K
        state.K += dK * dt
        state.t += dt

    return np.array(ts), np.array(Ks), np.array(Ys)

if __name__ == "__main__":
    ts, Ks, Ys = simulate(K0=50.0)
    print(f"初始K={Ks[0]:.1f}, 最终K={Ks[-1]:.1f}")
    print(f"初始Y={Ys[0]:.1f}, 最终Y={Ys[-1]:.1f}")
    print(f"稳态K*={(Params.s * Params.A / Params.delta)**(1/(1-Params.alpha)) * Params.L:.1f}")
```

这是整个项目可验证的起点。——从这个内核开始，逐步叠加复杂度。
